CORE CAPABILITIES

One framework. Clear boundaries.

Keep planning and simulation independent from transport-specific hardware code.

⌁

Kinematics

Forward and inverse kinematics with joint-limit validation for a planar 3-DOF arm.

◷

Motion planning

Scalar trapezoidal motion profiles and joint-space simulation stepping.

◇

Workspace & collision

Workspace estimates and 2D segment/circle collision primitives.

⇄

Hardware abstraction

A common driver interface, mock driver, command gate, and multi-arm coordinator.

▦

Eight arm profiles

Independent sample profiles to document IDs, joints, and limits.

✓

Testable core

CMake/CTest regression suites and GitHub Actions CI for the portable core.

Hardware safety notice

All controller examples default to disabled mock mode. No real vendor-specific motor driver is included. Software checks are not safety-rated and cannot replace a physical emergency stop, guarding, interlocks, or a system risk assessment.

GET STARTED

Build the portable core

Requirements: CMake 3.20+ and a C++23-capable compiler.

Terminal
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure
./build/forgearm_demo
